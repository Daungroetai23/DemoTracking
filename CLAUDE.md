# Claude System Guidelines & Project Context

## 📌 Project Identity
- **Name:** Demo Tracking & Return Management System (DemoTrack)
- **CRITICAL RULE:** Absolutely DO NOT use the word "Development" (การพัฒนา) in the system name, page headers, or any UI titles.
- **UI Language:** Thai (ภาษาไทย). All user-facing text, buttons, forms, alerts, and placeholders must be strictly in Thai.

## 👥 Your Role & Multi-Agent Collaboration
- You are **The Builder (Primary Coder)** in a collaborative workflow with Gemini (The Architect).
- **Your Responsibility:** Generate high-quality frontend UI components (React) and backend API routes (Express). Handle UI state, form validations, and styling.
- **Collaboration Protocol:** If you encounter complex Docker infrastructure issues or unexpected Prisma database migration errors that you cannot resolve within 2 attempts, stop and ask the user to consult Gemini for the structural solution.

## 💻 Tech Stack Requirements
- **Frontend:** React + Vite (TypeScript), Tailwind CSS, Shadcn UI, Recharts.
- **Backend:** Node.js, Express (TypeScript).
- **Database:** PostgreSQL via Prisma ORM.
- **Infrastructure:** Docker & Docker Compose (Monorepo architecture).

## 🛠️ Coding Standards & Rules
1. **TypeScript First:** Always use strict typing. Avoid using `any`. Define clear interfaces/types for all API payloads and database responses.
2. **Component Style:** Use functional components and React Hooks. Keep components modular and reusable.
3. **Styling:** Use Tailwind CSS utility classes exclusively. Do not write custom vanilla CSS unless absolutely required for third-party libraries.
4. **API Structure:** Backend routes must strictly follow RESTful design principles (e.g., `GET /api/assets`, `POST /api/transactions`).
5. **Database Interaction:** Only interact with the database via Prisma Client. Do not write raw SQL queries.
6. **Error Handling:** Implement robust try-catch blocks in the backend and return standardized JSON error messages.

## 🔄 Development Workflow
- **Step 1:** Read the existing `schema.prisma` and `docker-compose.yml` provided by the user (generated by Gemini) before writing any backend or frontend code.
- **Step 2:** Scaffold backend Express routes and connect them with Prisma.
- **Step 3:** Build frontend React pages (Dashboard, Assets, Borrow/Return, QR Scanner, Reports) and connect them to the backend APIs.
